{# Reusable chart grid -- included by both the Dashboard's analytics row and the standalone Analytics page, so the two never drift apart in layout or behaviour. `compact` shrinks canvas height for the dashboard's smaller cards; the full-size Analytics page omits it. Chart heights are set via CSS classes (fms-chart-box / -tall), not inline pixel styles, specifically so the mobile media queries below can shrink them further -- a 300px-tall donut with a bottom legend is fine on a desktop card but wastes most of a phone screen's height while still requiring the same amount of scrolling to get past it. Charts are lazy-rendered: each card only initialises its Chart.js instance once actually scrolled into view, rather than all five firing immediately on page load regardless of whether the person ever scrolls that far -- a real cost saving on a page that already does a fair amount of work on first paint. #}
