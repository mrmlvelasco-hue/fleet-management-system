    Automation & CLI Execution Guide
    Scheduled reports are delivered via the background CLI runner command.
    • Cron Setup: Execute the CLI runner command periodically (e.g., hourly) via system scheduler:
      flask report run-due
    • Idempotent Execution: Running the command frequently is safe; reports are dispatched only when their due time has elapsed.
    • Immediate Dispatch: Click Run Now on any active schedule to force an instant test email delivery.
